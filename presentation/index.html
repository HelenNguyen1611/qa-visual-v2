Correct evidence can still lead to
the wrong conclusion.

#1 · ANIMATION

“Service images are missing”

AI correctly describes the captured frame.

But the visual state is controlled by interaction / animation. A static screenshot does not fully represent the intended behaviour.

→
#8 · DYNAMIC STATE

“76% of the first screen is empty”

The 774px measurement can be correct.

But whether that empty state is actually a bug depends on animation and design intent.

The evidence can be correct while the conclusion is wrong → Human decides.
