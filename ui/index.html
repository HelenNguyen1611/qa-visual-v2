Trang web và design

Nhập URL trang chủ và link file Figma. Tool sẽ dò các trang của site rồi đoán frame tương ứng — bạn sửa lại ở bước sau.

Site có mật khẩu? (staging, Basic auth, hoặc trang login)

Chỉ giữ trong bộ nhớ của server, không lưu vào máy — mở lại trang là phải nhập lại. Muốn khỏi nhập mỗi lần thì đặt QA_HTTP_USER / QA_HTTP_PASS trong .env. Tool tự nhận biết là Basic auth (popup của browser) hay form login.

Bước này mất 15–30 giây: mở browser, đọc sitemap (hoặc dò link trang chủ), đọc file Figma và render frame.
